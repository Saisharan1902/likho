Everything you need to stop typing

Built for people who think faster than they type — and don't want their voice in someone else's cloud.

Private by default

Speech recognition runs on your Mac's GPU. Your voice is never uploaded, and never saved unless you ask.

Fast

Text appears about half a second after you let go. Models stay warm so the first dictation of the day is quick too.

Works in every app

Anywhere you can type: Slack, Gmail, Notes, ChatGPT, Claude, VS Code, Terminal. No plugins.

AI cleanup

Removes “um”s, keeps only what you meant after “no wait…”, formats spoken lists. Local model or your own API key.

Your words, your spelling

Teach it names and jargon. Set replacements: say “my email”, get your address.

A dashboard of your voice

Words per day, speaking speed, time saved, searchable history — all stored locally.

How it works

No windows to open, no buttons to click.

Hold the key

Hold Right ⌥ (or Fn, Right ⌘…). A small pill at the bottom of the screen shows it's listening. Double-tap for hands-free.

Talk naturally

Ramble, pause, correct yourself. “Let's meet Tuesday — no wait, Wednesday.”

Let go

Clean text is typed where your cursor is: “Let's meet Wednesday.” Your clipboard is left untouched.

See how much you say

The built-in dashboard tracks your words, speed and the time you've saved compared to typing — and keeps a searchable history of everything you've dictated.

  • Stats — words today, total words, speaking WPM, streaks
  • History — search, copy, compare raw vs cleaned text
  • Settings — hotkey, speech model, AI provider, all in one place

Your voice stays on your Mac

Most dictation apps send every word you say to a server. Dictly doesn't have one.

  • On-device speech recognition with open-source models (NVIDIA Parakeet, OpenAI Whisper) via Apple's MLX.
  • Audio is never written to disk unless you turn on recordings for playback.
  • AI cleanup can be local too — run a free model with Ollama, or bring your own API key. Off by default.
  • The dashboard only listens on your Mac (127.0.0.1) and blocks requests from websites.
  • Open source — read every line, or build it yourself.

Install

Dictly is currently installed from source — it takes about five minutes.

macOS 13 or laterApple Silicon (M1–M4)Python 3.12 (Homebrew)~4 GB disk for models
# 1. Get the code and set it up (downloads the speech model on first run)
git clone https://github.com/Saisharan1902/dictly.git
cd dictly
./run.sh

# 2. Optional: install it as a menu-bar app in /Applications
scripts/build_app.sh

# 3. Optional: free local AI cleanup
brew install ollama && brew services start ollama
ollama pull llama3.2:3b

On first launch, allow Dictly under System Settings → Privacy & Security → Microphone, Input Monitoring (to see the hotkey) and Accessibility (to type into other apps), then reopen it.

Questions

Is it really free?

Yes. Dictly is open source. There is no account and nothing to pay. If you choose a cloud AI provider for cleanup, that provider bills you directly for what you use.

Does it work offline?

Yes. After the models are downloaded once, speech recognition and local AI cleanup work with no internet connection.

Which languages does it support?

The default Parakeet model is English-only and the fastest. Switch to Whisper Large v3 Turbo in Settings for Hindi, Telugu, Tamil, Spanish, French, German, Japanese, Chinese and many more.

Why does it need Accessibility and Input Monitoring?

Input Monitoring lets Dictly notice when you hold the dictation key; Accessibility lets it press ⌘V to type into the app you're using. It only watches for its own key and Esc — it doesn't record your typing.

Does it work on Intel Macs?

Not yet. The speech models run on Apple Silicon's GPU through MLX.

How is this different from macOS dictation?

Dictly works the same way in every app, cleans up fillers and self-corrections, learns your vocabulary, lets you pick the model, and keeps a searchable history and stats — all locally.
