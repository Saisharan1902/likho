Features

Quietly brilliant.

Everything a dictation app should do — and nothing it shouldn't.

Private by design

Speech recognition runs on your Mac's GPU. Your voice is never uploaded, and never saved unless you ask.

Works everywhere

Slack, Gmail, Notes, ChatGPT, Claude, VS Code, Terminal — anywhere you can type. No plugins.

Says what you meant

Drops the “um”s, keeps only the correction after “no wait…”, formats spoken lists. Local AI or your own key.

Instant

Text lands about half a second after you let go. Models stay warm, so the first dictation of the day is quick too.

Your vocabulary

Teach it names and jargon once. Say “my email” and get your address.

Your voice, in numbers

Words per day, speaking speed, time saved and a searchable history — stored only on your Mac.

Install

Five minutes
to set up.

Dictly installs from source for now. A one-click app is on the roadmap.

  • macOS 13 or later, Apple Silicon
  • Python 3.12 — brew install python@3.12
  • About 4 GB of disk for the models
$ git clone https://github.com/Saisharan1902/dictly.git $ cd dictly $ ./run.sh # optional: install as a menu-bar app $ scripts/build_app.sh

On first launch, allow Dictly under System Settings → Privacy & Security → Microphone, Input Monitoring and Accessibility, then reopen it. Optional local AI cleanup: brew install ollama.

Is it really free?

Yes — Dictly is open source under the Apache 2.0 license. No account, no subscription. If you choose a cloud AI provider for cleanup, that provider bills you directly.

Does it work offline?

Yes. Once the models are downloaded, speech recognition and local AI cleanup need no internet connection.

Which languages does it support?

The default model (NVIDIA Parakeet) is English-only and the fastest. Switch to Whisper in Settings for Hindi, Telugu, Tamil, Spanish, French, German, Japanese, Chinese and many more.

Why does it ask for Accessibility and Input Monitoring?

Input Monitoring lets Dictly notice when you hold its key; Accessibility lets it paste into the app you're using. It only watches for its own key and Esc — never your typing.

Windows? Intel Macs?

Windows is next on the roadmap. Intel Macs aren't supported yet because the speech models run on Apple Silicon's GPU.
